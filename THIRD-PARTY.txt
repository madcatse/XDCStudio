Oklab colour transform
https://bottosson.github.io/posts/oklab/
Björn Ottosson's linear-sRGB to Oklab transform, made available by its
author in the public domain (also offered under MIT). The public-domain
formula is used in ColorMixer.cs. Palette pair search and model-measured Bayer search are project code.

CGA composite signal model
Numerical black/white transition measurements and resistor weights credited
to Andrew Jenner (reenigne). See docs/CGA-NTSC.txt for pinned source links,
model assumptions and tests. The signal/finite impulse response decoder
is independently implemented project code; no emulator code is linked.

Application icon
PC 5150 illustration generated with the built-in image_gen tool and edited
to display the user's supplied Bad Apple reference frame. Final PNG, ICO
and generation/edit prompts are included in assets/ in the source archive.

Static blue-noise mask
Independent implementation of periodic void-and-cluster mask construction,
following Robert Ulichney's published method and Gaussian filter discussion:
https://cv.ulichney.com/papers/1994-filter-design.pdf
No external mask image, library or implementation is bundled.
