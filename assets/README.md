# Application artwork

`pc5150-badapple.png` is a generated illustration of a PC 5150-style computer, edited to show a user-supplied frame from the Bad Apple silhouette animation on its CRT. `xdc-studio.ico` contains the Windows icon sizes derived from it. Generation/edit instructions are recorded in `imagegen-prompts.txt`.

The Bad Apple reference artwork remains attributable to its respective creators; the source-code MIT licence does not grant a new licence to that underlying artwork. This repository does not claim authorship of the reference frame or affiliation with its creators, IBM or the original XDC author.

No MIR video, soundtrack or complete Bad Apple animation is included.
