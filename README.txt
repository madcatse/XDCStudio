XDC Studio 0.7.2 — portable для Windows 10/11 x64

Справка: кнопка «Справка» справа внизу или F1. Открывается локальная
HTML-страница на языке интерфейса; доступна без интернета. Все параметры,
быстрый старт и благодарность автору XDC: docs/help.ru.html.

Запуск
Распакуйте ВЕСЬ архив и запустите XdcConverter.exe из верхней папки.
Установка .NET и права администратора не нужны. Подпапка app обязательна:
в ней библиотеки, FFmpeg и DOS-плеер; отдельно переносить EXE нельзя.

1. Выберите или перетащите MP4, MKV, WebM, MOV, AVI или другое видео.
2. Укажите выходной XDV и профиль: CGA Composite, чёрно-белый CGA, Tandy.
3. Выберите момент ползунком и настройте изображение.
4. Нажмите «Конвертировать в XDV». Готовый файл откроется в проигрывателе.

Подготовка изображения
• Гамма: 0,30–3,00; 1,00 — без коррекции, выше 1 — светлее.
• Насыщенность: 0–200%; 100% — исходная. Отключена для чёрно-белого CGA.
• Сила дизеринга: 0–100%; 0% — ближайший цвет, 100% — полное смешивание.
  Для «Без дизеринга» ползунок отключён. Узор закреплён на экране и
  повторяется одинаково на неподвижных кадрах.
• «Сбросить настройки цвета» возвращает 1,00 / 100% / 100%.
Все эти параметры влияют на готовый XDV. Предпросмотр обновляется сам.

Дизеринг и стабилизация — новое в 0.7
• Bayer 8×8 — прежняя матрица, остаётся вариантом по умолчанию.
• Bayer 4×4 — более короткий повторяющийся узор, меньше градаций смеси.
• Blue noise — неподвижная маска 8×8, рассчитанная методом Void-and-Cluster.
  Она не меняется от кадра к кадру. Иная фактура не всегда лучше Bayer.
• Без дизеринга — сплошные цвета без пространственного смешивания.
Каждая композитная маска измеряется через NTSC-модель; простая подмена
матрицы с сохранением старых цветовых таблиц не используется.

Стабилизация NTSC: 0–100%, по умолчанию 50%. Удерживает близкие по цвету
участки при слабом изменении исходника и учитывает стоимость обновлений
видеопамяти. Приоритет получают изменения с большим видимым улучшением
на затраченные такты 8088. История берётся из реально восстановленного
кадра; сильные изменения/смена сцены освобождают удержание.
0% выключает весь механизм, включая новый порядок обновлений. Bayer 8×8
со стабилизацией 0% воспроизводит результат 0.6. Более высокий уровень
увеличивает допустимое удержание; чрезмерный уровень может оставлять следы.
Стабилизация работает только в Composite с подбором NTSC. Tandy, B&W
и старый подбор «old mode» её не используют.

Предпросмотр отдельного кадра показывает цвет и выбранную маску без
временной истории. Результат стабилизации смотрите в проигрывателе готового
XDV. На каждой новой части история начинается заново. Нужны лишь несколько
кадров/буферов в RAM, не весь ролик. Стабилизация заметно увеличивает время
конвертации; с 0% остаётся быстрый путь предыдущей версии.

Подбор композитного цвета
В поле «Цвет CGA» выберите:
• NTSC · ранняя CGA — вариант по умолчанию;
• NTSC · поздняя CGA — подбор под другую схему видеокарты;
• old mode — прежний подбор для сравнения.
Новый алгоритм пропускает узоры дизеринга через модель композитного
сигнала, учитывая соседние точки, фильтрацию и ограничение яркости экрана.
Затем подбирает цвет и смесь по тому, что покажет эта модель монитора.
Сила дизеринга ограничивает долю второго цвета, после чего смесь выбирается
заново; 0% даёт только сплошные цвета. Гамма и насыщенность действуют до
подбора. Tandy сохраняет прежнее смешивание палитры в линейном свете.
Первый расчёт NTSC после запуска занимает около двух секунд на тестовом ПК;
таблицы хранятся только в RAM. Последующие кадры используют готовую таблицу.

Цель конвертации: выбранная CGA, оттенок 0, цветность 100%. Выбор варианта
NTSC также устанавливает соответствующий предпросмотр. Последующие правки
через кнопку «NTSC…» меняют только просмотр; подбор цвета остаётся прежним.
XDV не содержит признака ранней/поздней CGA: при открытии на другом ПК
выберите нужную модель монитора вручную.

Сравнение и композитный монитор
Слева исходный кадр, справа результат. Двигайте разделитель мышью или
стрелками после щелчка по изображению. Home/End показывают весь результат/
исходник. Отключите «Сравнить с исходником» для полного просмотра результата.
Половины используют один декодированный кадр и одинаковые пропорции.

Кнопка «NTSC…» в главном окне и проигрывателе открывает настройки монитора:
• ранний или поздний IBM CGA;
• оттенок −45…+45 градусов и цветность 0–200%;
• палитра XDC — прежний просмотр без моделирования сигнала.
Настройки общие для обоих окон, применяются сразу и сохраняются в
app/monitor-settings.json. Они влияют ТОЛЬКО на просмотр, не на XDV.

Модель обрабатывает 640 чёрно-белых точек строки CGA, переходы сигнала,
фазу цветовой поднесущей, фильтрацию яркости/цветности и декодирование NTSC.
Соседние пиксели влияют друг на друга. Модель не откалибрована по вашему
монитору: оттенки и резкость реального экрана могут отличаться. Подробности
и границы модели: docs/CGA-NTSC.txt. CGA RGB и Tandy остались без изменений.

Три профиля
CGA Composite: 160x200 или 160x100 с записью в нечётные строки CGA.
CGA RGB: 640x200, чёрно-белое. Tandy: 160x200, 16 цветов RGB.
Начальные настройки: 30 FPS, звук 22050 Гц, 150 КиБ/с, целостность 75%.
Для медленного накопителя снизьте поток/FPS; для динамичного видео
можно выбрать 160x100. Доступны дорожка звука, пропорции и деинтерлейсинг.
Длина 0 — до конца. Ползунок предпросмотра не меняет начало/длину экспорта.

Просмотр результата
Play, Pause, Stop; Stop возвращает к началу. Пробел переключает паузу.
Перемотка — ползунок или стрелки. Громкость справа, сохраняется после
перемотки; «Без звука» не сбрасывает уровень. Выбор части — над экраном.
Кадры и звук читаются из готового XDV. Ограничения потока видны в результате;
паузы реального диска и CGA snow не моделируются. Итог проверьте на 8088.
Можно перетащить существующий XDV или запустить XdcConverter.exe --play FILE.XDV.

Сохранение и RAM
Имя XDV: 1–8 букв A–Z, цифр или _. Папки могут содержать кириллицу/пробелы.
Существующий результат заменяется только после подтверждения и успешной
конвертации. Отмена/ошибка сохраняет старый файл. XDC_PLAY.EXE и BAT
копируются рядом с результатом. Длинные видео делятся по 60000 кадров.
Обработка RGB/PCM идёт в RAM; BMP/WAV и DOSBox не используются. Готовый
XDV записывается в .partial, проверяется и переименовывается. Временный
файл удаляется при отмене. Никакой распаковки runtime в TEMP при запуске.

Язык RU/EN выбирается над предпросмотром; настройка — app/ui-settings.json.
В верхней папке находятся только EXE, инструкции и папки app/docs.
Иконка: PC 5150 с присланным пользователем кадром Bad Apple на ЭЛТ-экране.

Командная строка
XdcConverter.exe --convert job.json
{"Input":"C:/video/MIR.webm","Output":"C:/video/MIR_CGA.XDV","Mode":1,
 "Gamma":1.15,"Saturation":1.2,"DitherStrength":65,
 "CompositeAlgorithm":"ntsc","CompositeNewCga":false,
 "Dither":"bayer4","TemporalStability":50}
Mode: 1 Composite, 2 B&W, 3 Tandy. Saturation в JSON — множитель 0–2.
CompositeAlgorithm: ntsc (по умолчанию) или legacy (old mode).
CompositeNewCga: true для поздней CGA; действует только при Mode=1 и ntsc.
Другие поля: HalfHeight, Fps, SampleRate, DiskRate, Integrity, Dither
(bayer/bayer4/blue/none), Fit (fit/crop/stretch), Deinterlace, Silent, AudioStream,
Start, Duration, SegmentFrames. Для явной перезаписи: Overwrite=true.
Результат: job.json.result.json, код завершения 0/1.
XdcConverter.exe --inspect FILE.XDV report.json
