# XDC Studio

Portable-конвертер для Windows x64: современные MP4, MKV, WebM и другие видео превращаются в XDV для проигрывателя XDC на компьютерах с 8088 под DOS.

Это самостоятельное развитие [оригинального XDC Джима Леонарда](https://github.com/MobyGamer/XDC), с сохранением истории проекта, Pascal-кода, лицензии и оригинального DOS-плеера.

## Возможности

- Три профиля: CGA Composite, чёрно-белый CGA RGB и Tandy.
- Подбор цветов через NTSC-модель ранней/поздней CGA; прежний палитровый подбор называется **old mode**.
- Гамма, насыщенность, сила дизеринга, Bayer 8×8 и 4×4, статический blue noise.
- Стабилизация между кадрами с учётом стоимости обновления видеопамяти 8088.
- Сравнение исходника и результата, перемотка, просмотр готового XDV со звуком и громкостью.
- Русский/английский интерфейс и локальная HTML-справка: кнопка справа внизу или F1.
- Обработка кадров и звука потоком в RAM, без DOSBox и промежуточных BMP/WAV. Готовый XDV сохраняется на диск.

## Запуск и сборка

Распакуйте весь portable ZIP и запустите `XdcConverter.exe`. Папки `app` и `docs` должны находиться рядом. Выберите короткий фрагмент, профиль и выходной файл, выполните конвертацию и посмотрите результат.

Для сборки нужны Windows x64 и PowerShell 7. Выполните `fetch-dependencies.ps1`, затем `build.ps1 -Package`. Инструкции и проверки: [BUILDING.txt](../BUILDING.txt), [описание тестов](../tests/README.md). Зависимости скачиваются с проверкой хешей в локальную `.tools`; системной установки нет.

Полная справка — `docs/help.ru.html` в дистрибутиве. Модель NTSC приближённая; окончательный результат проверяйте на своём старом ПК. Стабилизация увеличивает время конвертации.
