XDC Studio 0.7.0 — temporal NTSC stabilization and dither masks, 25.10.2026

New behaviour
Added Bayer 4x4 and a deterministic periodic 8x8 blue-noise rank mask, built
with void-and-cluster relaxation. Bayer 8x8 remains the default. Each mask
has its own candidate measurements through the existing NTSC decoder.
All masks remain fixed in screen coordinates: no random noise between frames.

Composite/NTSC stabilization defaults to 50% (0..100). It compares source
changes at full 8-bit precision, rendered candidate and actual reconstructed
VRAM. Near-equivalent 4x4 regions may be retained; visible improvements are
prioritized per estimated 8088 update cost. Exact encoder cycle/byte budgets
still apply. Large source changes release history; each output part starts
with fresh history. This is a heuristic, not optical-flow compensation or
a globally optimal update schedule. High strengths can increase persistence.
Zero disables both retention and the new priority order. Bayer 8x8 / zero
is byte-identical to 0.6. Mono, Tandy and legacy colour mode ignore stability.
Still preview shows colour/mask selection; temporal effects require XDV playback.

dither strength limits minority coverage and re-optimizes the pattern.

Это ограничение диагностического рендера. Снимок полного рабочего окна
